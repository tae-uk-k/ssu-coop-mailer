# ssu-coop-mailer

숭실대학교 총학생회 대외협력국 협찬 제안서 메일 자동발송 도구

기업 명단(엑셀)을 넣으면 **기업마다 다른 제안서를 만들어 PDF로 붙여 보냅니다.**

---

## 받는 법 (국원용)

[**mail-tool.zip 내려받기**](https://github.com/tae-uk-k/ssu-coop-mailer/releases/latest/download/mail-tool.zip)

1. 압축을 풉니다
2. 대외협력국장에게 받은 `credentials.json` 을 `설정` 폴더에 넣습니다
3. `메일자동화.exe` 를 더블클릭합니다

한 번 받으면 그 뒤로는 **켤 때마다 알아서 최신으로 맞춰집니다.**

> 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요.

자세한 사용법은 [사용설명서.md](사용설명서.md) 에 있습니다.

## 소스로 실행하려면

이 저장소를 받아 `실행하기.bat` 을 더블클릭하거나 `python run.py` 를 실행하세요.

## 무엇을 하는 프로그램인가

왼쪽 5단계를 위에서부터 채우면 발송 준비가 끝납니다.

| 단계 | 하는 일 |
| --- | --- |
| 1 파일 | 제안서 PPT와 기업 명단을 올립니다. 앱이 복사해 보관합니다 |
| 2 명단 | 이메일이 어느 열인지 고릅니다. 표에서 바로 고칠 수 있습니다 |
| 3 제안서 | PPT에서 찾은 `(자리)` 에 명단의 어느 열을 넣을지 짝짓습니다 |
| 4 메일 | 제목·본문을 쓰면 실제 나갈 모습이 바로 보입니다 |
| 5 보내기 | 기업마다 PPT 수정 → PDF 변환 → 명단 기록 → 발송 |

보낸 뒤 30분~1시간 지나 **반송 확인**을 누르면 되돌아온 주소를 명단에 표시합니다.

### 특징

- **PPT 자리를 코드에 박아두지 않습니다.** `(기업명)` 이든 `(회사명)` 이든 `(협찬사)` 든
  PPT를 훑어 찾아내고, 명단의 열과 짝지어 채웁니다
- **한글 조사를 알아서 맞춥니다.** 농심**을** / 오뚜기**를**, 농심**은** / 오뚜기**는**
- **중간에 멈춰도 됩니다.** 다시 시작하면 이미 보낸 곳은 건너뜁니다
- **켤 때 코드를 스스로 갱신합니다.** exe 는 그대로 두고 코드(160KB)만 바꿉니다

## 폴더 구조

```text
├─ 실행하기.bat        더블클릭하면 켜집니다
├─ run.py              실행하기.bat 이 부르는 파일
├─ 프로그램/           코드 (원격 갱신 대상)
│   ├─ app.py            창 틀 · 왼쪽 단계 레일
│   ├─ core.py           설정 · 파일 보관함 · 조사 · 명단
│   ├─ engine.py         PPT 자리 찾기/채우기 · PDF · Gmail · 발송
│   ├─ theme.py          색 · 글꼴 · 공용 위젯
│   ├─ screens.py        화면 7개
│   └─ updater.py        자동 갱신
├─ 설정/               계정 정보 (저장소에 올리지 않습니다)
├─ 행사별 작업/         행사별 자료 (저장소에 올리지 않습니다)
└─ 프로그램 만들기/     exe 만들기 · 업데이트 올리기
```

## 필요한 것

- Windows + **PowerPoint** (PDF 변환에 씁니다)
- Python 3.10 이상 (exe 로 쓰면 필요 없습니다)
- Gmail 계정 + Google Cloud 에서 받은 `credentials.json`

```bash
pip install -r "프로그램 만들기/requirements.txt"
```

## 관리자용

### exe 만들기

`프로그램 만들기/배포파일_만들기.bat` 을 더블클릭하면 `배포/` 폴더가 만들어집니다.
그 폴더를 통째로 전달하면 됩니다.

### 업데이트 올리기

코드를 고친 뒤:

```bash
python "프로그램 만들기/업데이트_올리기.py" 2026.09.01 "반송 확인 오류 수정"
```

`업로드/` 폴더가 열립니다. 그 안의 파일을 **Releases → Draft a new release** 에
전부 끌어다 놓고 Publish 하면, 국원들이 다음에 프로그램을 켤 때 자동으로 받아 갑니다.

**exe 는 다시 만들 필요 없습니다.** 코드만 바뀌니까요.
(`run.py` 나 라이브러리가 바뀔 때만 exe 를 다시 만듭니다)

### 저장소를 옮길 때

새 주소를 함께 알려주면 국원들 앱이 따라갑니다.

```bash
python "프로그램 만들기/업데이트_올리기.py" 2026.12.01 "저장소 이전" \
  "https://github.com/새계정/새저장소/releases/latest/download/manifest.json"
```
